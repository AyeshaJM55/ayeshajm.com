# Blog content guide

Blog posts live in `content/blog/`. Authors live in `content/authors/`.

While `npm run dev` is running, editing, adding, or deleting these Markdown files refreshes the site. Production content is generated by `npm run build`.

## New post template

```md
---
slug: my-post-slug
title: My Post Title
description: A concise summary for cards and search metadata.
publishedAt: 2026-08-01
author: ayesha-jm
category: Product Visualization
tags:
  - CGI
coverImage: /content/media/blog/my-post-slug/cover.jpg
coverAlt: Describe the cover image
draft: true
featured: false
---

Write the article here.
```

Set `draft: false` before publishing. Drafts appear in development and are excluded from production builds.

## New author template

```md
---
slug: author-slug
name: Author Name
role: Author Role
shortBio: A concise author biography.
avatar: /content/media/authors/author-slug.jpg
avatarAlt: Describe the author portrait
---

Write the longer biography here.
```

A post's `author` value must match an author file's `slug`.
